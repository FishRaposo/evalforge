# Security policy

Local trust boundaries (what never executes on the web path, API key handling),
redaction rules in evidence bundles, and the deliberately deferred surfaces are
covered in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability

Open a [security advisory](https://github.com/FishRaposo/evalforge/security/advisories/new)
or email fishraposo@gmail.com with the subject `[evalforge security]`. Please do
not open a public issue for a security report.

## Supported versions

Security fixes target the latest tagged release and `main`.
